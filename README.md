# ChildTrack AI

ChildTrack AI is an under-progress full-stack web platform designed to help in missing children identification and case reporting. The project aims to support citizens, NGOs, and police authorities by providing a centralized system for reporting missing/found children, managing cases, and later integrating AI-based face recognition.

## Project Status

🚧 This project is currently under development.
Core frontend and backend structure is completed. More advanced features like database integration, image upload, face recognition, CCTV matching, and alert notifications will be added step by step.

## Features Completed

* React frontend setup
* Node.js and Express backend setup
* Backend health check API
* Multi-page navigation
* Report missing child form
* Submit report to backend API
* View submitted reports on Missing Cases page
* Basic Police Dashboard UI

## How to Run Project Locally

### Clone the Repository

```bash
git clone https://github.com/your-username/ChildTrack-AI.git
cd ChildTrack-AI
```

### Run Frontend

```bash
cd client
npm install
npm run dev
```

### Run Backend

```bash
cd server
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

Backend runs on:

```bash
http://localhost:5000
```
